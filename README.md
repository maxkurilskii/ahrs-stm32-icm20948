# AHRS Estimation Using ICM-20948 and STM32F767ZI

Оценка ориентации объекта в пространстве (AHRS) с использованием 9-осевого IMU-сенсора **ICM-20948** на базе микроконтроллера **STM32F767ZI**.

## Project Overview

Репозиторий содержит проект AHRS, включающий:
- **Firmware** — прошивку микроконтроллера STM32F767ZI.
- **Host-side software** — ROS-ноды и Python-скрипты для последовательной коммуникации с микроконтроллером, обработки и визуализации измерений, калибровки датчика, кодирования и декодирования пакетов данных.

## Repository Branches

Репозиторий разделён на несколько веток, соответствующих различным этапам разработки.

**Default branch: `ros-noetic-integration`**

На данный момент это наиболее актуальная версия проекта, содержащая как прошивку микроконтроллера (`/firmware`), так и host-side программное обеспечение (`/imu_ros_pkg`).

**Other branches:**
- `main`
- `feature/imu_madgwick_spi_async`

Содержат более ранние рабочие версии прошивки, разработанные под Windows с использованием Keil µVision, а также Python-скрипты для последовательной коммуникации, визуализации и калибровки измерений.

## System Overview

Основные особенности реализации:

- **AHRS estimation:** расчёт ориентации выполняется непосредственно на STM32F767ZI с частотой 200 Гц.
- **UART communication:** передача измерений на хост осуществляется с той же частотой — 200 Гц.
- **Communication protocol:** для управления обменом данными реализован бинарный протокол взаимодействия по принципу Master-Slave. Каждый пакет включает Header, Payload и CRC16 для проверки целостности данных.
- **Data logging:** измерения сохраняются в CSV-файлы.
- **Visualization:** ориентация объекта и измерения IMU визуализируются в ROS RViz в режиме реального времени.

Пакет измерений, передаваемый с STM32:
```
+----------+----------+----------+----------+----------+
|  MARKER  | COMMAND  | LENGTH   | PAYLOAD  |  CRC16   |
+----------+----------+----------+----------+----------+
| 1 byte   | 1 byte   | 1 byte   | N bytes  | 2 bytes  |
+----------+----------+----------+----------+----------+
```

Основной поток данных:
1. ICM-20948 → STM32: получение акселерометра, гироскопа и магнитометра через SPI.
2. STM32: обработка измерений и вычисление ориентации с помощью алгоритма Madgwick (200 Hz).
3. STM32 → Host: передача результатов через UART с использованием бинарного протокола и CRC16.
4. Host: приём и декодирование пакетов, проверка CRC.
5. ROS: публикация измерений в sensor_msgs/Imu, трансляция TF.
6. Visualization: отображение ориентации в RViz, построение графиков и логирование измерений.


## ROS Package Structure

Основное host-side программное обеспечение расположено в пакете `imu_ros_pkg`.

### `/scripts`

Основные ROS-ноды, обеспечивающие:
- последовательную коммуникацию с микроконтроллером;
- получение и публикацию измерений в ROS-топик типа `sensor_msgs/Imu`;
- трансляцию TF-преобразований (TF Broadcast).

### `/utils`

Python-пакет, содержащий вспомогательные модули, разделённые на несколько подпакетов.

**`/uartcom`** — компоненты последовательной коммуникации:

- `uart_worker.py` — API для взаимодействия с STM32 и управления последовательной коммуникацией.
- `msg_parser.py` — парсер принимаемых бинарных пакетов.
- `msg_encoder.py` — кодировщик пакетов для отправки команд на микроконтроллер.
- `crc16.py` — реализация алгоритма CRC16.
- `protocol_codes.py` — коды команд управления и статусов коммуникации.
- `base_dataclasses.py` — структуры данных для хранения полученных измерений IMU и оценённой ориентации.

**`/measview`** — визуализация измерений с использованием Matplotlib с возможностью параллельного сохранения данных в CSV.

**`/measlog`** — инструменты логирования измерений в CSV-файлы.

**`/calibration`** — реализация эллипсоидной калибровки магнетометра.

### `/tests`

Python-пакет с тестами последовательной коммуникации и обмена данными. Для организации и запуска тестирования используется `pytest`.

### `/sim_description`

Описание экспериментального виртуального объекта, используемого для визуализации изменений ориентации в реальном времени.

### `/launch`

Launch-файлы для запуска необходимых ROS-нод и компонентов визуализации.
